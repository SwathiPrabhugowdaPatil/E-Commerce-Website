# Responsive E-Commerce Website

A modern, fully responsive E-Commerce landing page featuring smooth navigation, featured collections, product listings with rating badges, client reviews, blog updates, and a comprehensive footer section.

---

## 🚀 Features

* **Responsive Navigation:** Includes search, user profile, cart icons, and a mobile-friendly toggle menu.
* **Hero Section:** Highlights the **Winter Collection 2026** with direct call-to-action buttons.
* **Trending Products Showcase:** Displays products with custom tags (`Sale`, `New`, `Hot`), star ratings, interactive wishlist hearts, and pricing details.
* **Client Reviews:** Testimonials section showcasing customer feedback.
* **News & Updates:** Blog/update cards featuring dynamic dates and articles.
* **Footer & Contact Info:** Complete footer with social links, support resources, store navigation, and subscription details.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic markup structure
* **CSS3:** Custom styles and responsive layouts (`style.css`)
* **JavaScript:** Interactive UI functionality (`index.js`)
* **Icon Libraries:**
  * [Boxicons](https://boxicons.com/)
  * [Font Awesome](https://fontawesome.com/)
* **Google Fonts:**
  * IBM Plex Sans, Inter, Jost, Open Sans, Poppins, and Roboto
